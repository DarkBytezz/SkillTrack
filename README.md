# SkillTrack

A personal skill development tracker built using React, CSS, Spring Boot, and H2 Database.

## Features

- Add, edit, and delete skills.
- Set proficiency levels: Beginner, Intermediate, Advanced.
- Define learning goals and target dates.
- Track learning progress using percentages.
- Search skills.
- View dashboard statistics.
- Track upcoming learning targets.

## Tech Stack

**Frontend:** React, CSS, Axios, Lucide React

**Backend:** Java, Spring Boot, Spring Data JPA

**Database:** H2 Database

## Run Locally

### Backend

```bash
cd backend
./mvnw spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend: http://localhost:5173

Backend: http://localhost:8080
